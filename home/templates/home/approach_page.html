Learn how AI works. Build something of your own.

In teacher-guided projects, students choose a problem, explore what AI can do and test the solutions they create. They learn to explain their decisions and judge when an AI answer needs a second look.

From first prompt to project demo

With teacher guidance, students turn an idea into a simulator, website or digital prototype they can explain and share.

  1. {% icon 'scan-spark' %}

    Explore AI

    Try different prompts, compare AI’s answers and spot what needs checking.

  2. {% icon 'design-sketch' %}

    Design a solution

    Pick a problem, identify who it affects and decide what the project should do.

  3. {% icon 'sliders' %}

    Build and refine

    Use AI and coding tools suited to their age. Check how features respond and fix what doesn’t work.

  4. {% icon 'microphone' %}

    Share the work

    Demo the project, explain a design choice and share what they’d improve next.

Skills your child will learn

Students learn to guide AI, build digital projects and explain their ideas. Skills and tools vary by age and class.

{% icon 'scan-spark' %}

AI skills

  • Prompt design Give clear instructions, add context and refine prompts.
  • Text, image and voice AI Choose the right way to interact with AI for each task.
  • Patterns and predictions Explore how AI spots patterns and predicts results.
  • Data and model training Label examples and see how training data shapes results.
  • AI-assisted research Explore ideas and verify claims against reliable sources.
  • AI integration Add an AI feature to a simulator or website.
  • AI evaluation Test different examples, compare answers and spot errors.
  • Responsible AI Check for bias and protect personal information.
{% icon 'code' %}

Coding & digital creation

  • Vibe coding Describe what to build and refine it with an AI coding assistant.
  • Web development Create interactive pages with HTML, CSS and JavaScript.
  • Flowcharts and logic Map features and write rules for how they respond.
  • Testing and debugging Try real scenarios, find bugs and check fixes.
  • Git and GitHub Save code versions and collaborate on projects.
  • Website deployment Publish a working website that others can try.

Selected advanced projects

  • Django and APIs Build a Python web app and connect it to data or AI services.
  • Docker Package an app to run consistently on different computers.
{% icon 'people' %}

Creativity & leadership

  • Creative problem-solving Turn an everyday challenge into an idea worth testing.
  • Independent judgement Design for real users and back decisions with evidence.
  • Collaboration Share ideas, give feedback and make decisions together.
  • Public speaking Present a project and explain the choices behind it.

Find the right class for your child

Our youngest learners explore prompts, patterns and simple rules through guided activities. Older students deepen their AI understanding through web projects, coding and testing. Compare term classes and holiday workshops by age.
